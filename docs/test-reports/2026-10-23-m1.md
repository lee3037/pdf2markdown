# M1 本机开发与验证摘要

日期：2026-10-23（Asia/Shanghai）。范围：与本文同一提交的 M1 代码、依赖锁文件、合成样例及自动测试。

## 已实现

- 本机 Vue + FastAPI + 独立单 Worker，SQLite 持久化任务与当前编辑版本。
- PDF 上传、类型/大小/页数校验、损坏和加密文件拒绝。
- 排队与处理进度、任务列表、完成内容持久化、中断标记及重试。
- 明确标识的固定 Mock 内容，既不调用 MinerU，也不识别上传 PDF 正文。
- Markdown 编辑和安全阅读预览，按章节与完整段落打包的基础分块。
- 自定义分隔符、软目标大小、可选 Mock 来源说明；冲突校验及乐观版本控制。
- 阅读版和知识库版下载，下载前自动保存；未保存编辑的离开提示。
- 合成示例入口、原始 PDF 打开、窄屏布局、启动脚本和 CI 工作流。

## 环境

- macOS / Apple Silicon。
- Python 3.12.15、uv 0.13.5、Node.js 24.22.1、npm 12.0.2。
- Python 与 npm 依赖分别由 `uv.lock`、`frontend/package-lock.json` 锁定。
- 本机浏览器回归使用已安装的 Microsoft Edge（Chromium 引擎）；CI 默认使用 Playwright Chromium。
- 预览使用 5173/8000，浏览器自动测试使用 5174/8001 和独立临时数据目录。

## 限制与未验证项

- 真实 MinerU 接入、OCR 准确性和真实 PDF 内容转换未执行，属于 M2。
- M1 目标大小为软限制，整段、整表可能超限并显示提示；未实现语义细分、长表按行切分或续表合并，属于 M3。
- 没有真实 PDF 页码映射；来源选项只添加明确的 Mock 说明。
- M1 使用原生源码编辑框和新窗口打开原 PDF；Monaco、内嵌 PDF 对照属于 M4。
- pytest 有 1 条 Starlette TestClient 关于 httpx 兼容层的弃用提示，不影响当前测试通过；未来依赖升级时跟进。
- 启动脚本本轮验证平台为 macOS，使用 POSIX 进程组管理；Linux CI 由 GitHub Actions 验证，Windows 启动脚本尚未提供。
- 已加入 GitHub Actions；本机通过不代表云端工作流已通过，云端结果以仓库 Actions 状态为准。
