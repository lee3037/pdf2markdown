- 阅读其中 `mineru/cli/fast_api.py`，核实 `files[]`、`POST /tasks`、任务状态与结果查询，以及 `/file_parse` 同步兼容入口。

- 官方来源：https://pypi.org/project/mineru/3.1.1/ 。安装包源码与完整接口响应仅保存在被忽略的 `.local/`。

## 实际连接结果

- 按用户指定的网关地址尝试 HTTP `/openapi.json`、`/health`、根路径，以及同端口 HTTPS 的只读检查。
- 默认路由能建立 TCP 连接，但 HTTP 请求随后空响应/断开；HTTPS 未完成握手。只读路由检查显示默认经过隧道接口。
- 指定物理网卡的只读 HTTP 检查也超时；没有修改系统路由、代理、安全策略或远程服务配置。
- `scripts/probe_mineru.py` 返回 `available=false`、`code=connection_failed`、`pdf_submitted=false`。
- `scripts/live_smoke.py` 返回 `status=blocked`、`phase=probe`、`conversion_verified=false`，约 5.03 秒后结束。
- **未向指定网关提交 PDF，未取得真实解析结果；没有将模拟结果计为真实 OCR/表格验收。**
- 当前证据不足以确定问题来自网络、隧道、网关还是服务本身。已请求 Windows 本机 OpenAPI/health 返回及 app.py 路由定义，等待补充。

## 已实现

- real/mock 模式按任务持久化，历史列表显式标注 Mock/MinerU，旧 M1 任务保留 Mock 标识，远程失败不回退到固定示例。
- 先读取并验证 OpenAPI，再选择原生异步或声明的同步入口，不猜测自定义网关的上传路由。
- 连接超时、认证拒绝、重定向、结果格式错误等受控错误提示；凭据不发往响应中指定的其他地址。
- 上游任务 ID 持久化，重启恢复查询；查询超时继续查原任务；不确定提交及已过期任务需显式确认重提。
- 解析参数快照与认证隔离；切换服务地址不会将当前凭据用于旧任务指向的其他服务。
- 保留 raw.json、document.json、original.md；统一结构保留原始块与有效页号，未知信息不编造。
- 按原文件哈希、已知版本、接口指纹、请求参数、认证作用域和命名空间缓存成功解析，不缓存人工编辑。
- 网页显示远程服务检查结果、结构化信息、缓存命中和限制说明；原始 HTML 表格安全预览。
- 原生数据库无损加列迁移；启动脚本改为幂等终止标志，自动测试结束后关闭子服务并清理临时数据。
- 增加只读探测脚本及独立真实服务验收脚本。
